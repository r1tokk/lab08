## Опис проєкту
Проєкт реалізує незмінну модель абстрактного синтаксичного дерева (AST) для арифметичних виразів як алгебраїчний тип даних (ADT):
- **Вузли AST**: `Num`, `Add`, `Sub`, `Mul`, `Div` (описані через `@dataclass(frozen=True)` та `Union`/`TypeAlias`).
- **Обмежені літерали**: `Literal["+", "-", "*", "/"]` для позначення арифметичних операторів.
- **Структурна типізація**: `SupportsBinaryOp` та `Renders` на базі `typing.Protocol`.
- **Чисті операції через `match/case`**:
  - `eval_expr`: обчислення значення дерева з перевіркою ділення на нуль (`DivisionByZeroError`) та переповнення (`EvalOverflow`).
  - `fold_constants`: згортання констант (constant folding) без мутації вхідного дерева.
  - `render`: pretty-print представлення дерева у текстовому вигляді.
